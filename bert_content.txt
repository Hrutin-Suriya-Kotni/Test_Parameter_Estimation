Fluency Metric via Perplexity – 
Step A: Tokenization
We start with a sentence:

	•	= each word (or subword) in the sentence.
	•	Tokenization converts each word into a numeric token ID.
	•	The model only understands these numeric IDs, not raw text.
Example: Sentence: "I love cats" Token IDs might look like [40, 200, 1023].

Step B: Compute LM Log-Likelihood
A language model (LM) predicts the probability of a sequence of tokens. For a sequence , the probability is:

	•	Each token’s probability is conditioned on all previous tokens.
	•	This is the chain rule of probability.
To train/evaluate, we compute the average negative log-likelihood:

	•	This is exactly what CrossEntropyLoss in Transformers does.
	•	Smaller loss → model finds the sequence more probable → more fluent.

Step C: Convert to Perplexity
Perplexity is just an exponential transformation of the loss:

	•	Intuition: perplexity measures how “surprised” the model is by the sentence.
	•	Low perplexity → model is confident → fluent.
	•	High perplexity → model is surprised → awkward or less fluent.
Example:
	•	Sentence: "I love cats" → Perplexity ≈ 10 (high probability, fluent)
	•	Sentence: "Cats love I" → Perplexity ≈ 1000 (awkward, low probability)

Step D: Normalize Perplexity to [0,1]
Perplexity can be any positive number, but for a fluency score, we want a value between 0 and 1:

	•	σ = sigmoid function, squashes values into [0,1].
	•	Low perplexity → is large → sigmoid → F ≈ 1 → fluent.
	•	High perplexity → is small → sigmoid → F ≈ 0 → less fluent.
✅ This gives a normalized, interpretable fluency score.

3️⃣ How It Works Dimensionally
Let's track tensor shapes through the model (assuming GPT-2 style model):
	•	Input sentence: [seq_len] → token IDs
	•	Embedding layer: [seq_len] → [seq_len, 768]
	•	Each token gets mapped to a 768-dimensional vector.
	•	Transformer layers: [seq_len, 768] → [seq_len, 768]
	•	Contextualizes tokens based on the whole sentence.
	•	LM head (linear layer): [seq_len, 768] → [seq_len, vocab_size]
	•	Produces logits for next-token prediction.
	•	Softmax: [seq_len, vocab_size] → [seq_len, vocab_size]
	•	Converts logits to probabilities.
	•	Cross-entropy loss: [seq_len, vocab_size] → scalar
	•	Loss → perplexity → sigmoid → fluency score [0,1].

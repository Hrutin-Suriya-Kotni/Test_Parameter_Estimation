📝 STEP 1: Create .env file in project root
────────────────────────────────────────────────────────────────────────────────
Create a file named ".env" in this directory:
/Users/cleveres_tidiot/Documents/Vocab_AI/Parameter_Testing/.env


📝 STEP 2: Add your Gemini API key
────────────────────────────────────────────────────────────────────────────────
Add this content to the .env file:

# ===== GEMINI API CONFIGURATION =====
GEMINI_API_KEY=your_actual_api_key_here


📝 STEP 3: Get your Gemini API key
────────────────────────────────────────────────────────────────────────────────
1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the key and replace "your_actual_api_key_here" in .env


✅ VERIFICATION
────────────────────────────────────────────────────────────────────────────────
After setup, your .env file should look like:

GEMINI_API_KEY=AIzaSyAbc123defGHI456jklMNO789pqrSTU012

(This is just an example format, use your actual key)


🚀 READY TO RUN
────────────────────────────────────────────────────────────────────────────────
Once the .env file is created, you can run:

python run_gemini_full_test.py
